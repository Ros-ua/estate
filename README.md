# Карта хозяйства

**Сайт:** https://ros-ua.github.io/estate/

Две страницы об одном и том же:

| Страница | Что это |
|---|---|
| [`index.html`](index.html) — **Связи** | Проводник. Нажал на узел — увидел, с чем он связан, и пошёл дальше |
| [`doc.html`](doc.html) — **Документ** | То же самое сплошным текстом, читается сверху вниз |

## Как устроен проводник

Четыре типа узлов, 62 штуки:

- **Учётные записи** — Google, GitHub, Cloudflare, Meta, Telegram и отдельные учётки моделей;
- **Площадки** — где что физически крутится;
- **Проекты** — что мы делаем;
- **Сервисы** — модели, поиск, личные сервисы, служебное и программы флота.

Связь задаётся **один раз** — от проекта к его площадкам и сервисам. Обратные
(«кто на этой машине», «кто пользуется этим сервисом», «что висит на этой учётке»)
считаются на лету, поэтому рассинхрона между «туда» и «обратно» не бывает по устройству.

Ради чего это: одним нажатием видно, например, что **аккаунт Google держит 6 сервисов,
от которых зависят 8 проектов на 4 машинах**. Из таблицы это не читается, из проводника — сразу.

24.08 карту прогнали через сплошную перепроверку — 199 утверждений у источника. Нашлись ошибки
и здесь: связи, которых в коде нет, и связи, которые были, но потерялись. Исправлено.

## Это неполная версия, и так задумано

Страница публична — GitHub Pages отдаёт её всему интернету даже из приватного репозитория.
Поэтому здесь **нет**: адресов машин, окончаний ключей, путей к секретам, раздела с находками
обхода, раздела с белыми пятнами и списка единых точек отказа.

**Полная версия — в приватном `Ros-ua/estate-map`.** Значений ключей нет ни там, ни здесь.

## Как обновлять

**Проводник** правится прямо в `index.html` — данные лежат вверху скрипта отдельными списками,
код трогать не нужно. Проверка целостности перед выкладкой:

```bash
node --check <(python -c "import io;t=io.open('index.html',encoding='utf-8').read();print(t[t.index('<script>')+8:t.rindex('</script>')])")
```

**Документ** собирается из полной версии скриптом:

```bash
python make_public.py <полная>.html doc.html
```

Скрипт вырезает три раздела и три карточки, смягчает формулировки и **сам проверяет результат**:
ищет адреса машин, окончания ключей, пути к секретам — и **отказывается писать файл**, если
что-то нашлось или если раздел не нашёлся по имени. Молча пропустить лишнее нельзя.

После правок — push в `main`, сайт пересобирается сам.
