# Карта хозяйства — сайт

Оформленная страница: что где живёт, какой сервис в каком проекте, что когда истекает.

**Сайт:** https://ros-ua.github.io/estate/

## Это неполная версия, и так задумано

Страница публична — GitHub Pages отдаёт её всему интернету даже из приватного репозитория.
Поэтому сюда **не входят**:

- адреса машин;
- окончания ключей и пути к файлам с секретами;
- раздел «что нашли» — открытые слабые места;
- раздел «чего карта не знает» — что осталось без присмотра;
- раздел «общие ключи» — где у хозяйства единые точки отказа.

**Полная версия — в приватном репозитории `Ros-ua/estate-map`.** Значений ключей нет ни там, ни здесь.

## Как обновлять

Источник — полная карта. Публичная собирается из неё скриптом:

```bash
python make_public.py <полная>.html index.html
```

Скрипт вырезает три раздела и три карточки, смягчает формулировку про сроки и **сам проверяет
результат**: ищет IP-адреса, окончания ключей, `.env`, `client_secret`, пути к секретам —
и **отказывается записывать файл**, если что-то нашлось. Молча пропустить нельзя: если раздел
не найден по имени, скрипт тоже падает, а не публикует лишнее.

После сборки — обычный push в `main`, сайт пересобирается сам.
